Mark + lockup type tester

Every row sets the four matrix letters and the wordmark in one typeface. Bracket stroke scales to each font’s stem so the mark’s 16 : 14 bracket-to-stem ratio holds, and the whole mark is normalised to the same height. Matrix letters take the weight closest to the mark’s own stroke (14/62 = 0.226); the wordmark drops one weight below that and sits at 80% of the bracket height.

Spread is the centre-to-centre distance between the letters. The four cells stay a square about the fixed centre of the bracket, so the bracket never moves or changes size and the letters keep their size — they only move closer together or further apart, equally in both axes. 80 is the current design (marked * on the readout). Above about 110 the outer letters start to crowd the brackets; below about 62 wide faces begin to overlap.

Adding a font takes two steps — drop the .ttf into fonts/ and run tools/refresh-fonts.sh. That measures it and rebuilds fonts.css and catalog.js; this page reads both, so nothing here needs editing. Dank Mono is commercial (dank.sh, ~£40) so it can’t be included — Victor Mono and Cascadia Code are the free faces with the same cursive-italic character.

One caveat on the numbers. Stem width is measured by scanning across the H near the top of the glyph. On a serif face that scan crosses the serif rather than the stem, so the stem figure is inflated and the automatic weight choice is unreliable — Courier Prime reports 0.410 for its Bold, which is an artefact. Treat the measurements as sound for sans and monospace faces only, and judge the serifs by eye.
